# Admin

Scripts and source for services running on the `Admin` Raspberry Pi.

## Projects

| Folder | What |
| --- | --- |
| [ElOVerblik](ElOVerblik/) | Fetches electricity consumption from Eloverblik (Energinet DataHub) and estimates the meter reading. See [ElOVerblik/Overview.md](ElOVerblik/Overview.md). |
| [Power](Power/) | Scrapers that track outlet and clearance products on Power.dk and show what is new since the last run. See [Power/Overview.md](Power/Overview.md). |
| [Weblog-analyse](Weblog-analyse/) | Builds GoAccess web-traffic reports from cPanel access logs for dragic.com: fetch over FTPS, build reports per domain/month/day, keep an unoverwritable archive, and clean up on a schedule. See [Weblog-analyse/Overview.md](Weblog-analyse/Overview.md) for the script index, or [Weblog-analyse/README.md](Weblog-analyse/README.md) for the full setup guide. |
